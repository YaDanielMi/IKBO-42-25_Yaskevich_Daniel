# Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом
(Python 3 + tkinter, внешних зависимостей нет).

## Состояние

- [x] Этап 1. REPL (GUI, парсер, команды-заглушки, `exit`)
- [x] Этап 2. Конфигурация (параметры запуска, стартовый скрипт)

## Функции

- Окно с заголовком `Эмулятор - [username@hostname]`, имя пользователя и
  хоста берутся из реальной ОС.
- Приглашение `user@host:/$`, история команд на стрелках вверх/вниз.
- Парсер аргументов: одинарные и двойные кавычки, экранирование `\`,
  комментарии `# ...` (как в bash — только в начале слова).
- Команды:
  - `ls [аргументы...]` — заглушка, печатает имя и аргументы;
  - `cd [аргументы...]` — заглушка, печатает имя и аргументы;
  - `exit [код]` — завершает работу, код берётся по модулю 256.
- Ошибки: неизвестная команда, незакрытая кавычка, лишние аргументы
  у `exit`, нечисловой код у `exit`.

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | каталог на диске — физическое расположение VFS (на этапе 2 проверяется его существование) |
| `--script PATH` | стартовый скрипт с командами эмулятора |
| `--headless` | консольный режим без окна (для автоматизации и скриптов ОС) |

При запуске все параметры выводятся отладочными строками `[debug]` в
терминал (и в окно в GUI-режиме). Неверные значения дают сообщение
`Ошибка: ...` и код возврата 1.

## Стартовый скрипт

Текстовый файл UTF-8, одна команда эмулятора на строку.

- `# ...` — комментарий (в начале слова, вне кавычек); строка
  показывается в диалоге, но ничего не делает, как в настоящей оболочке;
- пустые строки пропускаются;
- при выполнении на экране виден и ввод (`user@host:/$ команда`), и
  вывод, как при диалоге с пользователем;
- ошибки команд не прерывают скрипт, `exit [код]` завершает его;
- если `exit` не встретился, эмулятор остаётся в интерактивном режиме
  (в окне; в `--headless` — читает команды со stdin до `exit` или конца
  ввода).

## Сборка и тесты

Сборка не требуется. Нужны Python 3.8+ и tkinter
(Debian/Ubuntu: `sudo apt install python3-tk`).

```sh
make test      # запуск unit-тестов
make lint      # flake8 (нужен pip install flake8)
```

## Запуск

```sh
./run.sh                                   # окно, без параметров
./run.sh --script examples/startup/basic.emu
./run.sh --vfs examples/vfs/minimal --script examples/startup/basic.emu
./run.sh --headless --script examples/startup/basic.emu
```

### Скрипты ОС для проверки параметров

```sh
scripts/stage2_params.sh           # все параметры, корректные значения
scripts/stage2_errors.sh           # неверные значения, неизвестные ключи
scripts/stage2_script_features.sh  # комментарии, ошибки, exit, stdin
```

## Пример сеанса

```text
user@host:/$ ls -l "my dir"
ls: заглушка, аргументы: ['-l', 'my dir']
user@host:/$ cd /tmp
cd: заглушка, аргументы: ['/tmp']
user@host:/$ foo
foo: команда не найдена
user@host:/$ ls "oops
ошибка разбора: не закрыта кавычка
user@host:/$ exit 1 2
exit: слишком много аргументов
user@host:/$ exit
```

## Структура

```text
src/                исходный код
tests/              unit-тесты
scripts/            скрипты ОС (bash), вызывающие эмулятор
examples/startup/   стартовые скрипты эмулятора (*.emu)
examples/vfs/       примеры каталогов для VFS
run.sh              запуск эмулятора
Makefile            цели test, lint, run
```
